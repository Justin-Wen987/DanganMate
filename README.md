# DanganMate 弹丸手册

一本为《弹丸论破》玩家准备的网页手册，把攻略、角色礼物偏好和背包记录放在一起。查流程、挑礼物、确认手里还有多少，都可以在这里完成。

### [打开弹丸手册 →](https://justin-wen987.github.io/DanganMate/)

免费使用，无需登录，无广告。支持电脑与手机浏览器，以及简体中文、English、日本語三种语言。

## 支持作品

| 作品 | 副标题 |
| --- | --- |
| **弹丸论破 1** | 希望的学园与绝望高中生 |
| **超级弹丸论破 2** | 再见绝望学园 |
| **新弹丸论破 V3** | 大家自相残杀的新学期 |

切换作品时，界面也会换成对应游戏的电子学生手册风格。各作品的背包记录分别保存。

## 可以做什么

### 查攻略

按章节查看游玩流程、搜查与学级裁判攻略，并查询隐藏收集、特殊礼物与可选事件。支持目录跳转与继续阅读。

攻略包含剧情信息，建议只打开当前游玩章节。

### 找到适合角色的礼物

在通讯录中查看角色资料，以及“非常喜欢”和“喜欢”的礼物；也可以从礼物反查喜欢它的角色，结合持有数量挑选赠礼。

### 管理礼物背包

按礼物编号、名称或角色搜索，筛选持有礼物，手动记录数量，赠送后扣除一件。没有 PC 存档的玩家也可以使用。

### 读取存档与备份记录

导入 Steam PC 版存档，在本机读取礼物数量；也可以导入、导出 JSON 备份，在其他设备或浏览器中继续使用自己的记录。

## 开始使用

1. 打开网站，选择正在游玩的作品。
2. 直接查阅攻略和礼物资料，或前往“存档与备份”导入游戏存档。
3. 没有可导入的存档时，手动填写礼物数量即可。

记录保存在当前浏览器中。更换浏览器、设备或清除网站数据前，请先导出 JSON 备份；记录不会自动跨设备同步。

## 存档导入说明

存档解析支持 Steam PC 版，文件只在本机读取，不上传，也不会修改原始存档。

| 作品 | 当前读取范围 |
| --- | --- |
| 弹丸论破 1 | 主线礼物 001–100；101–114 可手动记录 |
| 超级弹丸论破 2 | 礼物 001–140 |
| 新弹丸论破 V3 | 礼物 001–143 与黑白熊徽章数量 |

导入前会显示预览及覆盖提示，确认后替换当前作品的礼物记录。建议先导出备份，尤其是已有手动记录时。无法读取的数量会保留为未录入，请以导入预览为准。

其他平台玩家可以使用攻略、礼物查询、手动记录与 JSON 备份功能。

## 本地使用

需要 Node.js 22 或更高版本，无需安装依赖：

```powershell
node tools/serve.mjs
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173) 。首次选择作品，然后使用通讯录、礼物图鉴、背包、攻略和备份。

请通过 HTTP 打开，直接双击 index.html 的 file URL 会使浏览器拦截模块或资料库加载。

攻略及礼物资料的参考来源可在网站“资料与素材来源”中查看。不同语言版本的译名可能有差异，可结合礼物编号查找。
